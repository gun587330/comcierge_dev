# 이미지 파일 안내

Hero 섹션 배경 이미지를 이 폴더에 추가하세요.

## 파일명
- `hero-background.jpg` (또는 `.png`, `.webp` 등)

## 권장 사양
- 해상도: 1920x1080 이상
- 형식: JPG, PNG, WebP
- 용량: 500KB 이하 권장 (최적화된 이미지)

## 사용 방법
1. 배경으로 사용할 이미지를 이 폴더에 `hero-background.jpg`로 저장
2. 투명도는 `Hero.css`의 `.hero-bg-overlay`에서 `opacity` 값으로 조절 가능 (현재 0.2)

## 이미지 추천
- 장애인 근로자가 업무하는 모습
- 협업하는 모습
- 사무실 환경
- 포괄적인 업무 장면
